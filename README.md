Aurum – Restaurant Website

Aurum is a multi-page restaurant website developed as part of my college practical work using HTML and CSS.

The website presents a fine-dining restaurant concept with an Indian food menu, pricing details and a reservation enquiry form.

Features

- Restaurant homepage with an introduction
- Vegetarian and non-vegetarian food menu
- Food images and descriptions
- Price list displayed using an HTML table
- Reservation enquiry form
- Navigation between multiple webpages
- Consistent styling across all pages

Technologies Used

- HTML5
- CSS3

Through this project, I practised:

- Structuring webpages using HTML
